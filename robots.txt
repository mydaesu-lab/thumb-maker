# 주의: robots.txt 는 "도메인 최상위"에서만 인식됩니다.
#   - GitHub Pages 프로젝트 페이지(https://<계정>.github.io/<저장소>/)라면
#     이 파일은 https://<계정>.github.io/robots.txt 위치에 있어야 읽힙니다.
#     (저장소 안의 robots.txt 는 검색엔진이 요청하지 않습니다.)
#   - 커스텀 도메인(docs.example.com)을 붙였다면 그 도메인 루트에 두면 됩니다.
#   - 어느 경우든 sitemap.xml 은 검색엔진 콘솔에서 직접 제출할 수 있습니다.
